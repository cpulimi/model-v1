Figure 2

Why the memory curve is so steep

Vector Annealing allocates a full n × n matrix at 4 bytes per cell, whatever the coupling structure looks like. This model's couplings are local, so the matrix is overwhelmingly zeros — and gets emptier at every size.

Batching is the lever, and it already works

Every instance above ran as a single batch. Forcing the 100-hub instance into 5 batches with --max-z-vars-per-batch 8000 dropped the largest dense allocation from 8.3 GiB to 464 MiB and host memory from 58 MB to 19 MB, with no failures. Past roughly 126 hubs, batching stops being optional.

Reading it

What this does and does not tell you

Established

  • The pipeline runs clean end to end on all four sizes — load, batch, formulate, compile, emit QUBO, ceiling check — with no failures.
  • Problem size, construction time and total runtime all scale linearly with hub count. Nothing in the model or the pyqubo layer degrades.
  • Device memory scales quadratically and is the binding constraint. Single-batch headroom ends near 126 hubs at the configured ceiling, 210 at the hard maximum.
  • Host memory grows sub-linearly and stays under 1 GB. It is not a concern at these sizes.

Not yet measured — needs the VE card

These runs are preflight: they formulate and compile the QUBO but never sample it. Annealing time, solution cost and constraint violations are therefore absent by construction, not missing by oversight. Running va_benchmark.py --mode full on sfpga01n fills those columns.

When it does: judge the annealer on the raw violation counts, not the final ones. The repair and hub-prune post-pass drives final structural violations to zero almost regardless of what the sampler returned, so the final figure measures the post-pass, not Vector Annealing.

Worth raising with NEC

A density of 0.007% at 2.3 couplings per variable is an unusually poor fit for dense storage. If Vector Annealing V3.0.0 exposes any sparse or block ingest path, it is worth far more on this workload than any amount of sampling-parameter tuning — it would convert a quadratic memory wall back into a linear one.
